# Loan Approval Prediction System 🏦

A machine learning-based desktop application that predicts loan approval outcomes using applicant information.

The project combines a **Random Forest Classifier** with a Python **Tkinter GUI** to provide an interactive prediction interface.

## 🚀 Features

- Loan approval prediction
- Interactive desktop GUI
- Machine learning-based classification
- Model accuracy evaluation
- Input validation
- Real-time prediction results

## 📊 Input Features

The model uses:

- Age
- Salary
- Credit Score
- Loan Amount
- Employment Status

## 🤖 Machine Learning Model

The system uses a **Random Forest Classifier** implemented with Scikit-learn.

The dataset is divided into training and testing sets using an 80/20 split with a fixed random state for reproducibility.

## 🛠️ Tech Stack

- Python
- Pandas
- Scikit-learn
- Random Forest
- Tkinter
